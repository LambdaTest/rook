# Native scenario coverage for every industry and audience

The reviewed suite contains **144 native Rook scenarios**, with **18 in each of eight demo directories**. Each scenario has a concrete customer goal, business acceptance criteria, a feature revision reference, a fault tag and a provenance record. The suite uses `origin: authored`; it does not claim that all cases were autonomously generated by Rook.

The supplied tests are authored examples. Separately retained drafts show earlier Rook generation for Banking, Healthcare and Customer Support. Insurance includes authored agent definitions and scenarios. Neither set is an execution report.

## Use the scenarios

Follow your demo README to run `npm run rook:setup`, then `npm run rook` to open the interactive terminal. The [interactive guide](testing-with-rook.md) shows customer journeys, before/after comparisons, multi-turn, red-teaming and MCP.

For new exploration and generation, see [integration details](rook-integration.md). Review generated tests against the PRD before running them.

Cost tests require complete provider usage; missing usage must remain unverified. The illustrative latency and token budgets are demo settings.

Contributors can run `npm run rook:coverage` to validate all eight suites, their categories, feature references and repeated cases. See [verification](verification.md) for recorded execution results.
