# Recorded results

[reference/insurance-validation-summary.json](reference/insurance-validation-summary.json) is a portable summary of the recorded insurance tests. See [the result guide](../docs/insurance-validation.md) for the customer issue, findings and limitations.

Generated workspaces, conversations, full reports, browser captures and development history stay under `local/`, which is excluded from Git. The authored test definitions in each demo's `rook/` folder describe what to test; they are not execution results.
